# 下载与合并

1. 下载本目录全部 26 个 `班兰小程序补充交接包_2026-11-20.zip.001` 至 `.026` 文件，以及两个校验清单和 `合并分卷并校验.ps1`。
2. 保证这些文件位于同一文件夹，不要改名。
3. 在该文件夹打开 PowerShell，执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\合并分卷并校验.ps1
```

4. 脚本会先逐卷校验 SHA256，再合并出 `班兰小程序补充交接包_2026-11-20.zip`，最后核对整包 SHA256。
5. 看到“合并与校验通过”后，用 7-Zip 或 Windows 解压 ZIP。

整包 SHA256：

`07702f809c3e2534ef2ae07c2aaca9580cb73f327d6b034f6bb548e629df5fe0`

注意：`.001` 到 `.026` 必须全部下载，缺一卷都不能合并。
