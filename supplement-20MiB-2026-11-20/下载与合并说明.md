# GitHub 稳定下载分卷

本目录是 20 MiB GitHub 稳定镜像，共 116 卷。它与本地 26×90 MiB 正式包是同一个 ZIP，整包 SHA256 完全一致。

1. 下载 `.001` 至 `.116` 全部分卷，以及 `分卷SHA256校验清单.json` 和 `合并分卷并校验.ps1`。
2. 所有文件放在同一目录，不要改名。
3. 在该目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\合并分卷并校验.ps1
```

4. 脚本会校验每卷、合并 ZIP，并核对整包 SHA256。
